# 📱 ASIT Journal (Журнал АСИТ)

Приложение для Android, предназначенное для удобного ведения журнала, планирования и контроля курса аллерген-специфической иммунотерапии (АСИТ). Приложение помогает пациентам не пропускать прививки, корректно чередовать руки и безопасно адаптировать график при болезнях.

> ⚠️ **Отказ от ответственности:** Приложение является вспомогательным инструментом для планирования. Все изменения в дозировках и графике должны согласовываться с лечащим врачом.

## ✨ Ключевые возможности

- 🗓 **Автоматический расчет графика:** Генерация расписания от 7-й до 1-й ампулы с учетом индивидуальных интервалов (ежедневно, через день, через 2/3/4 дня).
- 💉 **Умное чередование рук:** Автоматическое переключение (Правая/Левая) происходит *только* после фактической отметки об успешном уколе.
- 🤒 **Обработка пропусков (болезнь):** При отметке "Пропущено" график не сдвигается автоматически. Даты будущих уколов пересчитываются только после того, как пропущенная прививка будет отмечена как "Сделано".
- ⚠️ **Контроль безопасности:** Если перерыв в курсе превышает 14 дней, приложение предупредит об этом и предложит пересоздать график с новой даты и дозировки по рекомендации врача.
- 🎨 **Цветовая индикация:** Каждая ампула имеет свой уникальный цвет. Просроченные плановые даты выделяются красным фоном и значком крестика.
- 🔔 **Push-уведомления:** Настраиваемые напоминания о предстоящих прививках (с указанием ампулы, дозы и руки).
- 📅 **Визуальный календарь:** Просмотр всего курса в формате сетки с цветными маркерами на датах уколов.
- ⚙️ **Гибкие настройки:** Возможность вручную изменить дозировки и интервалы для любой ампулы, а также выбрать дату старта и время уведомлений.
- 📤 **Экспорт данных:** Возможность поделиться текстовым журналом всех прививок через мессенджеры или почту.

## 🛠 Стек технологий

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material Design 3)
- **Архитектура:** MVVM (Model-View-ViewModel)
- **Локальная база данных:** Room Database + KSP (Kotlin Symbol Processing)
- **Асинхронность:** Kotlin Coroutines & StateFlow
- **Уведомления:** AlarmManager, BroadcastReceiver, Notification Channels
- **Сборка:** Gradle (Version Catalog `libs.versions.toml`)
- **Минимальная версия Android:** API 26 (Android 8.0)
